# Sales Kit — KZ Top-A Leads (2 недели валидации)

**Продукт:** `exports/kz-top-a-sales.xlsx` — 30 компаний с активными госконтрактами (Астана/Алматы), 26 телефонов, директора, суммы тендеров.

**Цель спринта:** 3 продажи списка ИЛИ 1 подтверждённый интерес от факторинга/банка. Дедлайн: 24 июня.

## Сегмент 1 — поставщики для строителей (продажа списка)

**Кому:** поставщики стройматериалов, спецтехники (аренда/продажа), СОУТ/охрана труда, логистика, IT для стройки, лизинг.

**Где брать контакты:** 2GIS «стройматериалы оптом», «аренда спецтехники» (Астана/Алматы) — у нас уже есть часть в БД.

### Скрипт холодного звонка (30 сек)

> Добрый день, [имя]. Меня зовут [имя], я делаю аналитику по госзакупкам в Казахстане.
> У меня есть список из 30 строительных компаний, которые **прямо сейчас исполняют госконтракты** — суммарно на [X] млрд тенге. У них есть деньги и текущие объекты.
> В списке: телефоны, директора, суммы контрактов. Таким компаниям обычно нужны [материалы/техника — под клиента].
> Стоит 50 000 ₸ разово. Могу прислать 3 строки бесплатно как пример — посмотрите качество. Куда отправить?

**Возражения:**
- «Мы и так знаем рынок» → «Список отсортирован по сумме активных контрактов — проверьте, есть ли у вас топ-5 из него. Если все есть — не покупайте.»
- «Дорого» → «Один контракт с любой компанией из списка окупает его в 100+ раз.»
- «Откуда данные?» → «Открытые источники: goszakup, stat.gov. Мы агрегируем и фильтруем — руками это неделя работы.»

### Письмо (email/WhatsApp)

> Тема: 30 строительных компаний с активными госконтрактами — Астана/Алматы
>
> Добрый день!
> Собрал список из 30 строительных компаний, которые сейчас исполняют госконтракты (суммы от 10 млн до 39 млрд ₸). Телефоны, директора, суммы — всё в одном файле.
> Это компании с подтверждённым бюджетом — лучшая база для продаж [материалов/техники/услуг].
> Цена: 50 000 ₸. Пришлю 3 строки бесплатно для оценки качества.
> [Имя, телефон]

> Победитель тендера = горячий лид для факторинга/гарантий: деньги по контракту придут через месяцы, оборотка нужна сейчас.
> Интересен пилот? Пришлю прошлую неделю бесплатно.
> [Имя, телефон]

## Где искать клиентов

### Сегмент 1 — из нашей же базы (главный канал)

Мы уже скрапили поставщиков: категории «Строительные материалы», «Проектирование зданий» (Астана + Алматы) лежат в `data/scrape2lead.db` с телефонами, WhatsApp и email.

```powershell
npx tsx scripts/make-prospects-list.mts
```

→ `exports/prospects-segment1.xlsx` — готовый список для обзвона с колонками статуса.

Добор, когда список кончится (тем же пайплайном, 1 прогон = ~35 контактов):
- «Аренда спецтехники», «Бетон», «Металлопрокат», «Электромонтажные работы»
- «Кровельные материалы», «Сантехника оптом», «Лизинг оборудования»

### Сегмент 2 — факторинг/банки (короткий список, руками)

| Кто | Канал |
|-----|-------|
| Halyk Bank (МСБ/факторинг) | сайт → форма для бизнеса, LinkedIn менеджеров |
| Forte, BCC, Freedom Bank (МСБ) | то же |
| KazFactoring, First Factoring KZ | сайт/WhatsApp |
| МФО для бизнеса (Solva Business и т.п.) | сайт |

Сюда не звонить вхолодную — письмо/LinkedIn с конкретикой: «еженедельно N свежих победителей тендеров с суммами».

### Каналы по приоритету (Казахстан)

1. **WhatsApp** — открываемость в КЗ максимальная; короткое сообщение + сэмпл-файл
2. **Звонок** — по скрипту выше, сразу после WhatsApp без ответа за день
3. **Telegram-чаты по госзакупкам** — поставщики там сидят; не спамить, 1 пост-оффер
4. Email — только для банков/факторинга

### Дневная рутина (~40 мин)

1. Открыть `prospects-segment1.xlsx`, взять следующие 5 строк
2. WhatsApp каждому: текст письма из сегмента 1 + `kz-top-a-sample-3.xlsx`
3. Вчерашним «без ответа» — звонок
4. Статус в колонку: `отправлено / ответил / звонил / купил / отказ`

## Критерии решения (24 июня)

- ≥3 продажи списка → направление A: автоматизировать доставку, расширять города
- интерес факторинга/банка → пивот C: ежедневный сбор новых контрактов, 2GIS из критического пути убрать
- 0 откликов на ~50 касаний → данные не проблема рынка; останавливаемся и переосмысляем
