## Реализация

- `buildRegisterView()` считает риски по строкам среза. Для старых полных срезов браузер повторяет расчёт по `rows`. В старой месячной сводке без строк доступны только сигналы сверки, для которых есть данные.
- Если отрицательный вал и превышение себестоимости срабатывают на одной строке, для суммы убытка берётся большая величина по модулю. Сумма расхождений с порталом складывается по модулю, в строках виден знак отклонения. Ожидаемое расхождение с НДС 12% отсекается.
- В копируемую сверку CRM входят ссылки на сделки с известным ID. Строки ОП без найденной сделки содержат дату, менеджера, заказчика, товар и сумму. Для договоров портала ссылка ЭГЗ формируется при наличии ID.
- Переходы из панели учитывают высоту закреплённых элементов и сохраняют выбранный месяц. При выборе исторического среза границей сверки остаётся последний доступный месяц реестра.
- Личный вид использует риски из собственного среза менеджера. Дисциплина загрузки файлов и сверка договоров с порталом скрыты в интерфейсе. В структурированных ретроправках личный вид показывает дату/имя файла без повторения прежнего менеджера в подписи.
