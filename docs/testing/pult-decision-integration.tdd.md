## Стыки (RED → GREEN, `tests/bitrix/salesPultPulseSources.test.ts`)

- **Потери → пульс:** красный пункт `losses-cheaper` из `summarizeRecentCheaperRejections` (сайт и утренний дайджест).
  Утром «Конкуренты» читаются из локальной базы; при `skipUpdates` (тесты) не читаются — см. журнал пульса.
- **Радар → пульс менеджера:** пульс менеджера строится из его отфильтрованного радара: свой горящий лот есть,
  чужого лота и имени коллеги в HTML нет, закрытых пунктов нет.
- **Склад → пульс:** жёлтый пункт `stock-demand` «Склад без расхода нужен в лотах» (штуки, без денег).
- **Склад → вид менеджера:** `stockForViewer` перенесён в `buildManagerVariant`: подсказки без ID чужих сделок
  при любой сборке; в `pult-variants.mts` осталась zod-проверка `payload.stock`.
- Поле `PulseItem.finance` теперь означает «закрытый пункт» (финансы, маржа, данные «Конкурентов»).
