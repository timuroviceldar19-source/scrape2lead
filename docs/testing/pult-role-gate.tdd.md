# Роли на пульте, шаг 1: проверка входа

Дата: 12–13.11.2026. База: `origin/main`, `8794ef6`. Ветка: `feat/pult-role-gate`.

## Зачем

Руководитель попросил роли: директора и РОП видят всё, менеджер — только своё, телевизор —
команду без денег. Сейчас пульт — две статические страницы, весь payload зашит в HTML, а
Cloudflare Access один на всех. Прятать чужое на экране нельзя: данные всё равно уходят в
браузер. Значит, каждая роль должна получать свою сборку страницы, а выбирать её — сервер.

Работа разбита на три шага. Этот — проверка входа и выбор варианта по роли. Вид менеджера и вид
телевизора — следующие PR. Пока секрета `PULT_ROLES` нет, всё работает как раньше.

## Решения

- **Где проверка.** Cloudflare Pages Functions, `functions/_middleware.ts`: срабатывает на каждом
  запросе после Access. Логика в `src/bitrix/salesPult/gate/` (без `node:`, тестируется в Vitest).
- **Кто пришёл.** Токен Access из `Cf-Access-Jwt-Assertion` (или куки `CF_Authorization`)
  проверяется по ключам команды `https://<team>.cloudflareaccess.com/cdn-cgi/access/certs`: подпись
  RS256, издатель, срок, `aud` (если задан). Заголовку с почтой без проверки подписи не верим.
  Ключи кэшируются на час; неизвестный `kid` перечитывает ключи не чаще раза в минуту.
- **Роли в секрете.** `PULT_ROLES`: команда, AUD-тег, «почта → all | tv | manager:<ID>». Почты не
  попадают ни в репозиторий, ни в лог: скрипт выкладки печатает только число пользователей по ролям.
  Конфиг вшивается в сборку промежуточного кода при выкладке (`exports/pult-gate/config.json`), так
  что отдельные секреты в Cloudflare не нужны.
- **Варианты.** Страницы лежат в `_r/<вариант>/index.html` и `reg.html`; прямые адреса `_r/…` и
  всё, кроме `/`, `/index.html`, `/reg`, `/reg.html`, отдают 404. Pages переадресует `*.html` на адрес
  без расширения — проверка идёт за переадресацией сама, только внутри `_r/`.
- **Безопасные отказы.** Нет токена или он плохой — «Нет доступа». Почты нет в списке — «Нет
  доступа» с этой почтой и выходом `/cdn-cgi/access/logout`. Вариант роли ещё не собран — «ещё не
  готов»; полный пульт вместо него никогда не отдаётся. Страницы нет в варианте — «эта страница вам
  недоступна» со ссылкой на пульт.
- **Кэш.** Все ответы `private, no-store`: страницы разные для разных людей.

## Как включить (после шагов 2 и 3)

1. Узнать AUD-тег приложения Access (Zero Trust → Access → Applications → приложение пульта).
2. Задать секрет репозитория `PULT_ROLES`.
3. Дождаться выкладки и проверить вход под каждой ролью.
