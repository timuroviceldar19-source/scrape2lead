# Роли на пульте, шаг 2: вид менеджера

Дата: 13.11.2026. База: `origin/main`, `69a8772`. Ветка: `feat/pult-manager-view`.

## Зачем

Согласованная раскладка: менеджер видит на главной свою строку, свои задачи и долги, по команде —
только общий итог; на «Выручке» — свои договоры и свой бонус, без маржи отдела и чужих цифр; в
«Планах» — свои закупки; «Рынок» целиком; «Радара» нет. Проверка входа (шаг 1) уже отдаёт роли
`manager:<ID>` вариант `_r/m<ID>/`; этот шаг его собирает.

## Решения

- **Данные режутся при сборке, а не на экране.** `src/bitrix/salesPult/variants/manager.ts`
  строит из полного payload вариант для одного менеджера; в его HTML нет чужих строк.
- **Главная.** Представление считается по полному пульту, поэтому итоги отдела (плитки месяца,
  итоги групп, темп звонков отдела) совпадают с полным пультом. Из него остаются только свои строки
  таблицы команды и разбора звонков. Payload: свои менеджер, задачи, долги, расхождения итогов,
  строки `contractSource.byManager`, сигналы (они всегда начинаются с `<b>Имя</b>:`), закрытые
  договоры без реестра. Заметки по звонкам называют людей, поэтому у менеджера остаётся только темп
  отдела (`buildDepartmentCallNotes`). Закрытые месяцы режутся так же.
- **«Планы»** пересобираются `buildPlansMonitorView` из сделок этого менеджера. Сборка теперь
  пишет все сделки в `exports/sales-pult/plan-deals.json` (на сайт файл не идёт). Нет файла — у
  менеджера «Планы сейчас недоступны», а не полные «Планы».
- **«Радар»** не попадает в payload; страница убирает вкладку и ссылку, `#radar-…` открывает «Сегодня».
- **«Выручка»** пересобирается `buildRegisterView` из строк реестра этого менеджера и его плана.
  Имена в реестре сопоставляются с сотрудником так же, как в сверке (`matchRegisterManager`:
  псевдоним из `register.managerAliases`, полное имя, однозначное имя). Обнулены бонус РОП, B2B-план
  и B2B-продажи отдела, `crmExtra`; нет списка сделок CRM и сверки с порталом (она по организациям,
  а не по людям). История месяцев: свои цифры, без сумм по дням (они по отделу), без партнёрских
  итогов месяца; дисциплина — свои строки, в правках скрыт прежний менеджер. Тексты первого блока:
  «ваша выручка», «до вашего плана», без «больше всех продал» и B2B.
- **«Я — …»** закреплено за менеджером: список из одного имени, выбор заблокирован, сохранённый в
  браузере выбор игнорируется, кнопки «Показать всю команду» нет.
- **Выкладка.** `scripts/pult-variants.mts` раскладывает `_r/all` и `_r/m<ID>` для каждого
  `manager:<ID>` из конфига ролей. Неизвестный ID — предупреждение, вариант не собирается (проверка
  входа покажет «ещё не готов»). Почты в лог не попадают.
- **Попутно: «Выручка» на телефоне.** У строк «Истории по месяцам» и таблиц «Дисциплины» колонки
  заданы в разметке, и на 375 px страница была шире экрана (и у полной «Выручки»). На телефоне у них
  теперь две колонки и нет строки заголовков, как у соседних таблиц.
