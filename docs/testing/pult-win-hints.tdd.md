## Правила подсказок

- История связывается по 12-значному БИН. Если БИН отсутствует на одной стороне, используется нормализованное название. Короткий список `wonCustomers` хранится один раз на товарную группу и включает победы за пределами ограниченных списков таблиц.
- Повторы между помесячными срезами и общим срезом исключаются по ID сделки. Запись протокола из таблицы конкурентов и очных встреч считается один раз по объявлению, лоту и победителю. Для CRM и протоколов без общего идентификатора счётчик складывает записи из обоих источников. Процент в бейдже — среднее отклонение от плана по записям с известной ценой. Для совпадений только по названию подробности находятся в подсказке бейджа.
- Шаблон ТС ищется сначала по номеру лота, затем по идентификатору объявления, затем в истории заказчика. Показываются лидер по числу побед по этому шаблону и его доля среди лотов с итогом.
- Медиана берётся из выигравших предложений конкурентов или, если таких цен нет, из наших побед. Для панели сначала ищется её диагональ. В варианте менеджера используется «Рынок», где при наличии только общей категории панелей показывается медиана категории. Запас начинается с 115% медианы, предупреждение о низкой цене — ниже 90%.
- Счётчики быстрых фильтров учитывают месяц, поиск и обычные фильтры. Копируются первые 15 строк текущей сортировки с суммами и ссылками CRM.
