## GREEN

- `insights.ts` сравнивает последний снимок с доступной историей и возвращает фактический
  интервал. Для недельного сравнения берётся дата ближе всего к семи дням из окна 5–10
  дней, при пустом окне — самый ранний доступный снимок. Если оба сравнения опираются
  на один снимок, на плитке показывается одна дельта.
- Платёжный календарь и нагрузка с КПН показаны отдельно. Подсказки из пометки и имени
  получателя выводят ближайшую дату от даты пульта. Интервал до пяти дней включительно
  выделяется цветом.
- Суммы и количество долгов считаются по строгим порогам с даты реализации. Неподвижный
  склад считается по начальным остаткам ведомостей с движением. Сверка с ТМЦ проверена
  на границе 1 000 ₸.
- Chromium проверяет порядок и предупреждения сверху, видимый топ должников, раскрытие
  списка с фильтром, бейдж платежа, три действия копирования, совместную работу поиска
  и фильтров склада, мобильную вёрстку, контраст WCAG AA и бизнес-формулировки.
  Старые проверки «Финансов» и первой волны сохранены, номер «Дебиторов» обновлён на 02.
  Контрольный прогон после уплотнения мобильных плиток защитил размер текста плашки
  дефицита: сохранены 12 px при ширине 375 px.

## Локальный Pages

HTML из `financeWorkbook({ stockSheets: true })` собран с помощью `renderFinanceHtml`.
`npx tsx scripts/pult-variants.mts` собрал директорский и менеджерский варианты.
`npx wrangler pages dev exports/sales-pult-deploy --port 8788` отдал `/fin.html`
с HTTP 200. Chromium на 375 и 1440 px проверил отсутствие горизонтального переполнения,
быстрый переход, реальный буфер обмена и фильтр склада. На 375 px также проверено
положение колонки «Компания» при горизонтальной прокрутке таблиц.

Маршруты с ролями проверялись на тех же собранных файлах через `handleGateRequest` с
локальным ключом и выдуманными JWT Cloudflare Access. Проверка интерфейса через Wrangler
использовала пустой конфиг ролей.

```text

> tsc -p tsconfig.json --noEmit

$ npm test -- --maxWorkers=4
```

Для PDF-тестов использована временная среда Python с совместимой версией ReportLab.
Повторный прогон с четырьмя воркерами прошёл после тайм-аута браузерного теста
в первом полном запуске. Временные файлы в `exports/` удалены после проверки.
