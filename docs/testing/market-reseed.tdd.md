База: origin/main, 613a898 (PR #114). Все данные новых тестов синтетические.
Релиз, боевые файлы рынка, Bitrix и расписание не изменялись; workflow не запускался.

## RED

Сначала изменён тест условия импорта комплектов, добавлены проверки входа,
порядка сброса, защит, строгого Seed и флагов запуска. Добавлен отдельный тест
функции обновления окна: обычная ошибка, строгая ошибка, успешная замена окна
с сохранением keepContractIds и истории за пределами окна.

Первый запуск двух файлов: оба файла красные; два теста упали, два прошли,
набор функции не загрузился из-за отсутствующего updateWindow.js.
Причины: нет market_reseed, прежнее условие импорта, функция ещё не вынесена.

## GREEN

- market_reseed — boolean, по умолчанию false. Проверка несовместимых входов
  выполняется до всех шагов actions/cache.
- Сброс между восстановлением кэша рынка и Seed выводит только число позиций
  и удаляет units-2026.json. Seed скачивает прежний файл из market-seed.
- Ошибка скачивания при восстановлении завершает job; без восстановления
  сохранено прежнее предупреждение. Импорт комплектов включён любым из двух входов.
- Только site с market_reseed получает --market-update --market-update-strict.
- Блок обновления окна вынесен в src/kz/market/updateWindow.ts. Строгий режим
  пробрасывает ошибку; обычный сохраняет прежний текст предупреждения.
  При ошибке выгрузки байты файла не меняются в обоих режимах.
- fetchMarketUnits, второй проход, порог отказов, ows, mergeMarketUnits,
  keepContractIds и причины ошибок PR #114 не изменялись.
- Число позиций в копии и после импорта передаётся через GITHUB_ENV.
  После успешного обновления выводится ровно одна строка восстановления
  с тремя количествами; штатные счётчики окна сохраняются.
- Команды workflow дополнительно выполняются тестами в bash с подставными
  gh/npm: защита режимов и backfill, обычная/строгая ошибка Seed, флаги site.
  Сетевых обращений, операций с настоящим кэшем и запуска workflow в этих тестах нет.

## После слияния (выполняет оператор)

Actions → Sales Pult F3 → Run workflow: mode = site, market_reseed = true,
market_backfill_from пустой. Ожидаемая длительность — около 15 минут.

Запускать в выходные или в будни после 15:00 UTC. Все режимы сохраняют кэш рынка,
следующий запуск восстанавливает последний сохранённый. Утренний запуск
(04:00 UTC) или вечерний (13:00 UTC), начавшийся раньше восстановления,
может позднее сохранить старый кэш поверх восстановленного.

В логе должна появиться одна строка:
«[Рынок] Восстановление: в копии …, после импорта комплектов …, после обновления окна …»,
а также обычные счётчики обновления окна. Только количества, без деталей договоров.
При провале Seed, импорта или строгого обновления job падает: последующие шаги,
деплой и успешное post-сохранение actions/cache не выполняются.

Повторный полный npm test: 157 файлов прошли, 8 упали, 3 пропущены;
1869 тестов прошли, 10 упали, 25 пропущены. Все падения относятся к указанным
браузерным/PDF ограничениям (в том числе ошибкам browser setup/cleanup).
