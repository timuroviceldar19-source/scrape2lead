# Разделение дебиторов на просроченную и непросроченную задолженность

## Задача

На странице «Финансы» (`fin.html`) Пульта F3 разделить таблицу дебиторов на две отдельные части со своими итогами — **просроченную** и **непросроченную задолженность** — без изменения формата Excel-отчёта финансиста (используя уже существующую с 20.11.2026 колонку «Дата оплаты»).

## Решения

1. **Чистая классификация в `src/bitrix/salesPult/finance/insights.ts` (`classifyDebtorsByPayment`):**
   - Включается, только если в отчёте есть колонка `paymentDate` или хотя бы у одной строки заполнена дата оплаты; для старых отчётов без дат оплаты возвращает `null`, чтобы страница не выдумывала «просрочку» без договорного срока.
   - **Просроченная задолженность:** `paymentDate` строго раньше даты сборки (`daysToPay < 0`). Считаются количество, общая сумма, разбивка по компаниям и `top5` / `top10` (сначала крупнейшие по сумме, затем по длительности просрочки).
   - **Непросроченная задолженность:** оплата сегодня (`daysToPay === 0`), позже (`daysToPay > 0`) или без даты оплаты (с отдельным счётчиком `undated`, чтобы пропущенные даты в файле сразу были видны). Сумма обеих групп всегда точно равна итогу `R.debtors.total`.
   - `over30` / `over60` в `insights.debt` не менялись, чтобы утренний пульс (`pulse.ts`) и старые сценарии остались совместимыми.
2. **Отображение на странице (`fin.client.js`, `fin.css`):**
   - На плитке «Дебиторка» в блоке `01 Деньги и долги` сразу показаны суммы просроченной (красным) и непросроченной задолженности; быстрая ссылка ведёт к просрочке.
   - В блоке `02 Дебиторы` фокус-карточка показывает сводку «Просроченная / Непросроченная», Топ-5 просроченных должников с датой оплаты и числом дней просрочки, кнопку быстрого раскрытия и копирование просроченных для чата.
   - Ниже вместо одного списка `#debtMainBox` выводятся два свёрнутых блока с итогами в заголовке и строкой `Итого` внизу каждой таблицы:
     - `#debtOverdueBox` («Просроченная задолженность»)
     - `#debtCurrentBox` («Непросроченная задолженность»)
   - «Проблемные долги» (`#debtProblemBox`, суды / исполнительные листы / списания) остаются отдельным блоком ниже.
   - У каждой таблицы независимые фильтр по компании и кнопка «Показать все» при >12 строках, общая сортировка по всем столбцам (с сохранением открытого состояния и клавиатурного фокуса) и адаптивная раскладка для телефона (`375px`).
   - Парсер Excel (`parseReport.ts`) и `FINANCE_PARSE_VERSION` менять не пришлось: колонка `paymentDate` уже разбирается и лежит в кэше.
