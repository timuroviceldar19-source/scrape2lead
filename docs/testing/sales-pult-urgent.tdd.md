## Решения

- Общий помощник имён получает только выбранные ID и карту уже известных имён.
  Fallback кэшируется вместе с именами: повторного запроса при отказе нет.
  Транспортная ошибка не интерполируется в предупреждение.
- Дополнительные имена для пульта загружаются после отбора двух видов срочных
  расхождений; история с `historyOnly` завершает сбор раньше этого шага.
- `contractSource.reconciliation` передаётся отдельным полем `RegisterPagePayload`;
  runner страницы передаёт его рендереру только для месяца `asOfDate`.
- Суммы второй части блока 04 показаны в тенге без округления до миллионов.
- Номера блоков и список сцен ТВ сохранены. Код `chatReport.ts`, таблиц команды
  и тендеров, подробностей менеджера не менялся.
