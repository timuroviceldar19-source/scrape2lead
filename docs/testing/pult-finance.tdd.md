# Финансы: ежедневный отчёт финансиста на пульте

Дата: 17.11.2026. База: `origin/main`, `6d0f091`. Ветка: `feat/pult-finance`.

## Зачем

Руководитель попросил «финансовый пульт». Финансист каждый день кладёт `Ежедневный отчет.xlsx`
в групповой чат Битрикс24 «Финансовый отчет». Пульт должен забирать его оттуда так же, как
реестр ОП, и показывать отдельной страницей. Решение пользователя: «Финансы» видят все, у кого
есть вход на пульт (полный вид); менеджеру и телевизору страница не собирается.

## Откуда берётся файл

- Файлы чата лежат в его папке на Диске. Реестр ОП устроен так же: `register.diskFolderId` 89975 —
  это папка `chat53225`, чат задачи. Для финансов `finance.diskFolderId` = папка чата
  (`im.disk.folder.get` по CHAT_ID). Вебхук пульта состоит в чате, `disk.folder.getchildren`
  отдаёт файл со ссылкой на скачивание.
- В имени файла нет даты, каждый день имя то же (Битрикс добавляет «(1)», «(2)»). Самый свежий —
  по `CREATE_TIME`, при равенстве по большему ID. Берутся только `.xlsx`.
- Старые файлы остаются в папке, из них собирается история по дням (графики под плитками). Кэш
  `data/register/finance.json` зашифрован ключом истории реестра (`REGISTER_HISTORY_KEY`) и лежит
  в том же кэше Actions `gz-register-v1-`, поэтому workflow не менялся, кроме проверки Access.
  Кэш только экономит скачивания: потеряется или ключ сменится — история соберётся из папки
  заново (до 20 файлов за запуск, сначала свежие).
- Файл не скачался (сеть, HTTP) — на следующем запуске пробуем снова. Файл скачался, но не
  разобрался — запоминаем и не качаем каждый раз; на странице пояснение и прошлый отчёт.
  Файл удалили из чата — он уходит и из истории.
- Без ключа (локальный запуск) кэша нет: разбирается только самый свежий файл. Для отладки есть
  `--finance-file <путь>`.

## Разбор (лист «Ежед.»)

Файл собран руками, список дебиторов каждый день разной длины, и всё ниже сдвигается. Поэтому
блоки ищутся по подписям:

- **Счета:** первая шапка «дата | компании… | ИТОГО» задаёт колонки компаний; все строки с теми же
  названиями в тех же колонках — шапки блоков. Под шапкой с датой строки с кодом счёта.
  Дата отчёта — самая поздняя дата блока с выручкой (6xxx). Прибыль = 6xxx − 7000 − (7100…8999),
  так же, как формулы сводки вверху листа; сводка («Выручка» | прошлый месяц | текущий период)
  сверяется с расчётом. Счета < 6000 на дату отчёта — «Счета на конец дня». Строка «КПН» — оценка налога.
- **Деньги:** шапка «банки… | Всего | ТМЦ» (не строка «ДС»), компании до «Итого».
- **Движение денег за день:** две строки с датами над «Без поступлении» и «Потрачено»; показывается,
  только если «сегодня» равно деньгам на счетах.
- **Поступления:** плательщики — колонки под «Поступления», компании — строки до «Итого».
- **Дебиторы:** «Дебиторы | компании… | Дата реализации | ИТОГО»; ниже без подписи та же шапка —
  проблемные долги (суды, исполнительные листы). «Кредиторы» и «Кредит …» — строки в той же колонке.
- **Платежи:** «Календарь | Сумма | Основание» до строки итога; ниже блок «КПН к оплате» пропускается
  (налог берём из блока счетов), затем «Прочие платежи» и список «Топ-…» со своим «Итого».
- `B1 = TODAY()` — не дата данных, не используется. Лист «Дебиторы» устаревший, не читается.
- Пропал обязательный блок (счета, деньги, дебиторы) — ошибка, показывается прошлый отчёт.
  Итоги не сходятся — предупреждение на странице, разбор продолжается.

## Приватность

Репозиторий и логи Actions публичные. В коде нет названий компаний, банков и контрагентов —
всё читается из файла. В логе только число файлов, дата отчёта и число предупреждений; причины
ошибок разбора без сумм и названий. Тесты — на выдуманном файле
`tests/fixtures/sales-pult/financeWorkbook.ts`; настоящий файл в репозиторий не кладётся.

## Роли

- `fin.html` собирается в `exports/sales-pult` и кладётся только в `_r/all/` (`scripts/pult-variants.mts`).
- Проверка входа знает адреса `/fin`, `/fin/`, `/fin.html`; у вида без страницы — «эта страница
  вам недоступна». В виде менеджера ссылка «Финансы» убирается и с главной, и с «Выручки».
- Пока секрет `PULT_ROLES` не задан, «Финансы» видят все, кого пускает Access, — так решил пользователь.
- В шаг выкладки добавлена проверка Access для `/fin` до и после выкладки и на адресе выкладки.

## Страница

Разделы: деньги и долги (6 плиток с графиком по дням), прибыль по компаниям (текущий период и
прошлый месяц, КПН), платежи (календарь против денег на счетах, прочие и «Топ» свёрнуты), дебиторы
(фильтр по компании, 12 строк и «показать все», давность с реализации цветом: >30 жёлтый, >60
красный; проблемные долги с примечаниями), деньги по банкам (колонки без денег скрыты), поступления
за день, счета и курсы, предупреждения сверки. Отчёт старше 3 дней помечается.

В меню на всех страницах семь разделов; чтобы «Конкуренты» влезали в 375 px, у меню на ≤480 px
отступ 3 px и шрифт 11 px (было 4 px и 11,5 px).
