# AutoService Radar KZ

## Product Definition
**AutoService Radar KZ** — это B2B-продукт, предоставляющий верифицированные контакты организаций автомобильного рынка Казахстана. Продукт фокусируется на сборе, нормализации и обогащении публичных данных о коммерческих предприятиях для целей лидогенерации и прямых B2B-продаж.

**География:** Астана (с возможностью масштабирования на Алматы, Шымкент и другие города).  
**Категории:** Автосервисы, Шиномонтаж, Автомойки, Магазины автозапчастей.

## Target Buyers (Целевые покупатели продукта)
1. **Поставщики масел и автохимии** — ищут новые точки сбыта и хотят охватить независимые СТО.
2. **Поставщики шин** — нуждаются в актуальной базе шиномонтажей для сезонных оптовых поставок.
3. **Оптовики автозапчастей** — расширяют дилерскую сеть, ищут магазины для прямых поставок.
4. **Поставщики оборудования для СТО** — требуют точного таргетинга для долгих циклов B2B-продаж.
5. **Провайдеры CRM / Телефонии / POS-систем** — нуждаются в массовых рассылках и обзвонах для демонстрации SaaS-продуктов.

## MVP Package
Коммерческий MVP-пакет для Астаны включает:
- **Объем:** 300–500 верифицированных лидов (по 100–150 на каждую из 4 категорий).
- **Формат:** Excel (XLSX) с 4 вкладками:
  1. **Leads:** Полный список компаний с полями: название, категория, город, район/адрес, телефон, WhatsApp, Telegram, сайт, email, источник, дата проверки, оценка полноты данных, готовность к контакту, примечания.
  2. **Summary:** Сводная статистика (всего лидов, по категориям, с телефоном, с мессенджерами, с сайтом, с email, полные/неполные, удаленные дубликаты).
  3. **Buyer Segments:** Рекомендации по использованию базы для разных сегментов покупателей (почему покупают, предлагаемый оффер, рекомендуемые фильтры).
  4. **Outreach Notes:** Готовые скрипты для WhatsApp, холодных звонков, follow-up сообщений и обработка основных возражений.

## Pricing Hypothesis
- **Тестовый пакет (50 лидов):** Бесплатно или по символической цене для демонстрации качества данных.
- **Базовый пакет (300 лидов, 1 город):** $150–$250 (в зависимости от полноты данных: наличие email, сайта, мессенджеров).
- **Расширенный пакет (500+ лидов, несколько городов или регулярное обновление):** $400–$600/мес.
- **Модель:** Разовая продажа файла или подписка на ежемесячное обновление базы.

## Data Source & Compliance Disclaimer (Важно)
- **Demo-статус текущих артефактов:** Сгенерированный в репозитории Mock XLSX-файл является **исключительно демонстрацией формата** структуры данных. Он не содержит реальных контактов и не может быть использован как продаваемая база.
- **Требования к Production:** Реальный коммерческий датасет должен формироваться исключительно из устойчивых и верифицированных источников (см. `docs/data-sourcing-options.md`). Мы не используем и не поддерживаем методы обхода капчи (captcha bypass) или нелегального скрейпинга.
- **Отсутствие персональных данных:** Строго запрещено собирать и хранить персональные данные физических лиц (сотрудников). Собираются только публичные контактные данные организаций (B2B).
- **Право на удаление (Opt-out / Remove-on-request):** В продукте действует строгая политика удаления данных по запросу. Если организация обращается с требованием удалить свои данные, они безоговорочно удаляются из всех активных наборов и архивов в течение 48 часов.

## Compliance Notes (Соответствие требованиям)
При сборе и обработке данных строго соблюдаются следующие принципы:
1. **Только публичные B2B-данные:** Собираются исключительно контактные данные организаций, опубликованные в открытых источниках.
2. **Прозрачность источника:** Для каждого лида сохраняется URL источника и дата сбора данных.
3. **Цель использования:** Данные предоставляются исключительно для B2B-коммуникаций и не могут быть использованы для спама или мошеннических действий.
