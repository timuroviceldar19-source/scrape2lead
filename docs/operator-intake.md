# Operator Intake Tool

Инструмент для полуавтоматического добора лидов в Real Sample 50 без использования live scraping, прокси или платного 2GIS Contact API.

## 🎯 Назначение
Позволяет оператору вручную скопировать текст карточки компании из 2GIS (или другого источника), извлечь из него структурированные данные и безопасно добавить их в `exports/autoservice-radar-astana-real-sample-50.xlsx` с автоматической проверкой на дубликаты и расчетом полноты данных.

## 🛠️ Режимы работы

### 1. Режим парсинга текста (`--parse-text`)
Принимает сырой текст и извлекает из него телефоны, WhatsApp, Telegram, email и сайты.

**Использование:**
```bash
# Передача текста напрямую
npm run operator:intake -- --parse-text "Тел: +7 (777) 123-45-67, сайт: https://example.kz, wa.me/77771234567"

# Чтение из файла
npm run operator:intake -- --parse-text raw_card_text.txt
```

**Вывод:** Нормализованный JSON с извлеченными полями (без записи в XLSX).

### 2. Режим добавления в базу (`--append`)
Принимает JSON с данными лида, проверяет дубликаты, рассчитывает `completeness_score` и добавляет строку в Real Sample 50.

**Использование:**
```bash
# Передача JSON строкой
npm run operator:intake -- --append '{"company_name": "АвтоСервис", "phone": "77771234567", "address": "Астана, ул. Примерная 1", "source_url": "https://2gis.kz/astana/firm/..."}'

# Чтение из JSON файла
npm run operator:intake -- --append new_lead.json
```

**Обязательные поля для успешного добавления:**
- `company_name` (Название компании)
- `phone` (Телефон в формате 77771234567)
- `source_url` (Ссылка на источник, обязательна для compliance)

**Необязательные, но рекомендуемые поля:**
- `category` (Категория, например: "Автосервисы")
- `city` (По умолчанию: "Астана")
- `address` (Адрес)
- `whatsapp` (Телефон для WhatsApp)
- `telegram` (Юзернейм или ссылка)
- `website` (Сайт)
- `email` (Email)
- `notes` (Заметки)

## 📊 Система оценки полноты (Completeness Score)
Инструмент автоматически рассчитывает балл (0–100) на основе наличия полей:
- **Телефон:** +40 баллов
- **WhatsApp:** +20 баллов
- **Адрес:** +20 баллов
- **Источник (source_url):** +10 баллов
- **Сайт или Email:** +10 баллов

**Пороги:**
- **>= 80:** Статус "Проверено", `ready_for_outreach` = "Да".
- **60–79:** Статус "Требует проверки", `ready_for_outreach` = "Нет".
- **40–59:** Добавляется, но требует значительного дополнения.
- **< 40:** **Отклоняется** (необходим как минимум телефон и источник).

## 🛡️ Проверка на дубликаты
Перед добавлением инструмент проверяет существующие строки в Real Sample 50 по трем критериям:
1. Нормализованный телефон (совпадение цифр, 8 и +7 считаются одинаковыми).
2. Комбинация нормализованного названия компании + телефона.
3. Точное совпадение `source_url`.

При обнаружении дубликата операция прерывается.

## 📁 Резервное копирование
Перед каждой модификацией `autoservice-radar-astana-real-sample-50.xlsx` создается автоматический бэкап с временной меткой:
`autoservice-radar-astana-real-sample-50.backup-YYYY-MM-DDTHH-MM-SS.xlsx`

## ⚖️ Правила Compliance
1. **Только публичные B2B контакты:** Собирайте только те данные, которые организация сама разместила в открытом доступе (2GIS, сайт, соцсети).
2. **Запрет на личные данные:** Не собирайте личные номера телефонов сотрудников, если они не указаны как официальные контакты организации.
3. **Обязательный источник:** Поле `source_url` должно быть заполнено всегда для аудита происхождения данных.
4. **Remove-on-request:** Если компания запрашивает удаление из базы, запись должна быть удалена из XLSX при следующем обновлении.
5. **Никакого live scraping:** Этот инструмент предназначен исключительно для ручной вставки данных оператором. Не используйте его для автоматизации обхода CAPTCHA или массового парсинга.

## 💡 Пример рабочего процесса оператора
1. Откройте карточку компании в 2GIS в браузере.
2. Выделите и скопируйте весь текст карточки (Название, адрес, телефоны, ссылки).
3. Запустите: `npm run operator:intake -- --parse-text "вставленный_текст"`
4. Скопируйте полученный JSON, добавьте `company_name`, `category` и `source_url`.
5. Запустите: `npm run operator:intake -- --append '{"company_name": "...", ...}'`
6. Убедитесь в сообщении об успешном добавлении и проверьте балл полноты.
