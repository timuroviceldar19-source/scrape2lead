# Шаблон еженедельного дайджеста (Telegram-канал)

Публичный пост: **5–10 строк**, без телефонов и email. Телефоны — только в платном пакете или личке (3 бесплатно).

---

## Формат одной строки (HTML в Telegram)

```
<b>N.</b> <b>Компания</b>
📋 Предмет закупки
💰 <b>Сумма</b>
🏛 Заказчик (если есть)
🔗 <a href="...">goszakup</a>
```

Между блоками — разделитель `────────────────`.

Код: `src/kz/channelDigest.ts` · parse_mode: `HTML`

---

## Ротация ниш по неделям

| Неделя | `--channel-niche` | Комментарий |
|--------|-------------------|-------------|
| 1 | `Строительство` | Общая стройка |
| 2 | `ПСД / освещение` | Кейс madi |
| 3 | `Снабжение` | Поставщики |
| 4 | `Kaspi-селлеры` | Раз в 2 недели — ручной пост про Kaspi (отдельный шаблон) |

## Kaspi (раз в 2 недели, ручной пост)

```
📊 Kaspi-селлеры · Авто · Астана

Собираем магазины с Kaspi.kz по категории + городу, дополняем контакты через 2GIS.

В канале — обзор ниши. Телефоны магазинов — в личку.

Kaspi-селлеры — отдельный продукт, пишите «KASPI» в @TheMainGame12
```

---

## Чего не публиковать

- Телефоны, email, ФИО директоров
- Полные Excel-файлы в канал
- «Вся база Казахстана»
- Цены в каждом посте (только в личке после запроса)
