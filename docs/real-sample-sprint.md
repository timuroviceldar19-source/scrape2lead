# Real Sample Sprint: AutoService Radar KZ

## Цель Sample
Подготовить реальный, верифицированный набор данных (sample dataset) для демонстрации потенциальным B2B-клиентам качества и полноты базы контактов авто-рынка Астаны. Данный sample служит доказательством ценности (Proof of Value) перед продажей полного пакета.

**Важно:** Текущий сгенерированный Mock XLSX является исключительно демонстрацией формата. Для реальных продаж требуется набор данных, собранный из устойчивых и коммерчески безопасных источников.

## Целевые категории и объем
- **География:** Астана
- **Общий target:** 100–150 компаний
- **Распределение:** 25–40 компаний на каждую из следующих категорий:
  1. Автосервисы (СТО, ремонт двигателей, кузовной ремонт)
  2. Шиномонтаж
  3. Автомойки
  4. Магазины автозапчастей

## Структура данных (Поля)
Каждая запись в sample dataset должна содержать следующие поля для обеспечения максимальной полезности для отдела продаж:

| Поле | Описание |
|------|----------|
| `company_name` | Официальное название компании или бренда |
| `category` | Категория бизнеса (из списка выше) |
| `city` | Город (Астана) |
| `address` | Физический адрес с указанием района (для логистики) |
| `phone` | Основной контактный телефон организации |
| `whatsapp` | Наличие и номер WhatsApp (да/нет или прямой номер) |
| `telegram` | Наличие и номер Telegram (да/нет или прямой номер) |
| `website` | Официальный сайт компании |
| `email` | Корпоративный email (info, sales, и т.д.) |
| `source_url` | Прямая ссылка на источник данных (для прозрачности) |
| `checked_at` | Дата последней проверки актуальности контакта (YYYY-MM-DD) |
| `verification_status` | Статус проверки: `verified` (дозвонились), `unverified` (требует проверки), `invalid` (номер не работает) |
| `notes` | Дополнительные сведения (например: "только оптом", "есть склад", "ЛПР: Иван") |

## Критерии качества для Sample
- Не менее 80% записей должны иметь рабочий телефон (`verification_status: verified`).
- Не менее 60% записей должны иметь заполненное поле `email` или `website`.
- Полное отсутствие персональных данных физических лиц (только B2B контакты).
