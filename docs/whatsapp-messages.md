# Готовые сообщения WhatsApp — копировать как есть

## 1. Первое касание (+ сразу приложить kz-top-a-sample-3.xlsx)

> Добрый день! Вы поставляете материалы/услуги строительным компаниям?
>
> У меня список 30 строительных компаний Астаны и Алматы, которые прямо сейчас исполняют госконтракты — суммарно более 44 млрд тенге. У них есть бюджеты и текущие объекты.
>
> В списке: прямые телефоны (26 из 30), директора, суммы и количество контрактов.
>
> Прикладываю 3 компании из списка бесплатно — оцените качество данных. Полная версия — 50 000 ₸ разово.

*Сразу вторым сообщением — файл сэмпла.*

> Данные на дату покупки, источники: goszakup.gov.kz и stat.gov.kz.

## 4. Ответ на «дорого»

> Понимаю. Смотрите на это так: один новый клиент из списка — это контракт на сотни тысяч или миллионы тенге. 50 000 ₸ — меньше, чем день работы менеджера по поиску таких контактов вручную.
>
> Могу предложить вариант: 10 компаний за 25 000 ₸ — попробуете на части списка.

---

## 5. Ответ на «откуда данные / это законно?»

> Все данные из открытых государственных источников: goszakup.gov.kz (реестр госзакупок) и stat.gov.kz (реестр юрлиц). Мы их агрегируем, фильтруем по активным контрактам и сортируем по бюджетам — вручную такая выборка занимает неделю.

---

## 6. Ответ на «мы и так всех знаем»

> Возможно! Проверьте по сэмплу: если все 3 компании уже ваши клиенты — список вам правда не нужен. Но обычно из 30 хотя бы 20 оказываются новыми.

## Правила

1. Сообщение → сразу файл сэмпла вторым сообщением (не ждать вопроса)
2. Не отвечает 24 часа → фоллоу-ап №2
3. Не отвечает после фоллоу-апа → звонок на следующий день
4. После каждого касания — статус в `prospects-segment1.xlsx`
5. Ответил «нет» — статус `отказ`, не трогать
