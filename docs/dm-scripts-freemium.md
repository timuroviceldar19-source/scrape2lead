# DM / WhatsApp — freemium-скрипты

Принцип: **канал + демо с маскировкой** → платный кастом.  
**Бесплатных полных контактов в личку не отдаём.**

Полная модель: [freemium-tiers.md](./freemium-tiers.md)

---

## 1. Первый контакт (Threads / WhatsApp)

```
Добрый день! Собираем лиды из goszakup под нишу.

Уточните:
1) Ниша (что продаёте / что ищете)?
2) Город — Астана, Алматы или весь КЗ?
3) Goszakup или Kaspi-селлеры?

Демо Excel (~50 строк, контакты замаскированы) — подписчикам канала:
t.me/ai_leads_kz

Полный список с телефонами — пакетом или кастом.
```

---

## 2. После интереса

```
Формат подходит?

Goszakup (победители тендеров + контакты):
• 5 компаний — 9 900 ₸
• 15 компаний — 19 900 ₸

Kaspi (магазины по категории):
• 15 магазинов — 9 900 ₸

Каждый понедельник — дайджест в Telegram (без телефонов):
t.me/ai_leads_kz

Подписчикам — демо ~50 строк (маскировка). Полный список под вашу нишу — пакетом или кастом.
```

---

## 3. «Хочу базу за подписку»

```
Всю базу по КЗ не отдаём — устаревает каждую неделю.

Вместо этого:
• Подписка на канал — демо ~50 строк (маскировка)
• Репост/коммент — мини-выборка ~15 строк
• Платно — готовые лиды: «100 компаний в Алматы с контрактом и контактом под вашу задачу»

Напишите нишу — соберём под вас.
```

---

## 4. «Так неудобно» / «надо писать запрос»

```
Понимаю. Сейчас на старте — вручную, зато под вашу задачу, не «база на весь КЗ».

Упрощаем:
• один шаблон запроса (ниша + город)
• ответ файлом в Excel
• дайджест в канале — просто читаете: t.me/ai_leads_kz

Кабинет — позже.
```

---

## 5. «Сколько стоит вся база?»

```
«Вся база по всему КЗ» не продаём.

Продаём готовые лиды под нишу:
Goszakup: 5 / 9 900 ₸ · 15 / 19 900 ₸
Kaspi: 15 / 9 900 ₸

Пример: «15 победителей тендеров по освещению в Астане, с телефоном и ссылкой на контракт».

Напишите нишу — оценим объём и срок.
```

---

## 6. «История по БИН?» / «Выборка по товару?»

```
По БИН — да: договоры goszakup + реквизиты stat.gov (открытые данные).

Выборка:
• список БИН → обогащение
• ключевые слова в закупках («освещение», «ПСД», «бетон»)
• Kaspi — категория + город

Напишите задачу одной фразой — оценим пакет.
```

## 7. Kaspi (askhat-тип)

```
Да, Kaspi-селлеры — отдельный продукт.

Магазин + телефон с профиля + рейтинг + обогащение 2GIS.

Полная категория — пакет 15 за 9 900 ₸.

Категория и город?
```

## 8. Кастом по нише (madi-тип)

```
Понял: {ниша}, весь КЗ, победители + контакты.

Полный список — пакет 5/15 или отдельная цена под объём (согласуем после уточнения задачи).
```

---

## 9. Мини-выборка за репост / комментарий (пятница)

```
Спасибо за реакцию! Пришлю мини-выборку ~15 компаний (демо, контакты частично скрыты).

Полные телефоны под вашу нишу — пакет 5/15 или кастом.
```

Генерация: `npm run kz:freemium-demo -- --mini`
