# Data Sourcing Options: AutoService Radar KZ

Для формирования реального, коммерчески безопасного и качественного sample dataset рассматриваются следующие варианты сбора данных. **Важно:** Мы не используем и не планируем использовать методы обхода капчи (captcha bypass) или нелегального скрейпинга, нарушающего условия использования платформ.

## Option A: Official / Licensed 2GIS API Route
Использование официального API 2GIS (или аналогичных лицензированных картографических сервисов) для легального получения структурированных данных об организациях.
- **Cost:** Высокая (подписка на API или оплата за запросы).
- **Risk:** Минимальный (полностью легально, нет риска блокировок или юридических претензий).
- **Speed:** Высокая (мгновенное получение структурированных данных).
- **Quality:** Высокая (официальные данные, актуальные адреса и телефоны).
- **Compliance Notes:** Полное соответствие законодательству. Данные предоставляются правообладателем.
- **When to use:** Для масштабирования продукта, когда есть бюджет и требуется гарантированная легальность и стабильность поставок данных.

## Option B: Manually Verified Public B2B Sample
Ручной или полуавтоматизированный сбор данных из открытых источников (сайты компаний, публичные бизнес-справочники, социальные сети бизнеса) с последующей ручной верификацией (дозвон).
- **Cost:** Низкая (только затраты времени оператора/менеджера).
- **Risk:** Низкий/Средний (собираются только публичные данные, нет нарушения ToS при ручном просмотре).
- **Speed:** Низкая (ограничена пропускной способностью человека).
- **Quality:** Очень высокая (ручная проверка гарантирует, что номер работает, а компания существует).
- **Compliance Notes:** Допустимо при сборе исключительно публичных B2B-контактов. Запрещен сбор личных данных сотрудников.
- **When to use:** Идеально для текущего **Real Sample Sprint**. Позволяет быстро собрать 100-150 высококачественных, проверенных лидов для демонстрации клиентам без крупных инвестиций в API.

## Option C: Client-Provided CRM Enrichment
Клиент предоставляет свою существующую, но устаревшую или неполную базу, а мы обогащаем её (добавляем актуальные сайты, email, мессенджеры, статусы).
- **Cost:** Средняя (оплата за услугу обогащения).
- **Risk:** Низкий (клиент сам предоставляет данные, мы только дополняем их из публичных источников).
- **Speed:** Высокая (пакетная обработка).
- **Quality:** Зависит от исходных данных клиента, но ценность на выходе высокая.
- **Compliance Notes:** Требуется гарантия от клиента, что он имеет право на обработку этих данных. Мы обогащаем только публичными сведениями.
- **When to use:** Когда клиент уже имеет базу, но жалуется на низкую конверсию из-за устаревших контактов. Отличный upsell к основному продукту.

## Option D: Paid Data Provider / Aggregator API
Покупка готовых баз или использование API специализированных B2B-агрегаторов (например, Spark, местные бизнес-реестры).
- **Cost:** Средняя/Высокая.
- **Risk:** Средний (необходимо тщательно проверять легальность сбора данных провайдером).
- **Speed:** Высокая (готовые датасеты).
- **Quality:** Переменная (часто много дубликатов, устаревших номеров или "мусорных" записей).
- **Compliance Notes:** Требуется строгий аудит провайдера на предмет соответствия законам о персональных данных и сбора публичной информации.
- **When to use:** Как резервный источник для массового покрытия, если Option A слишком дорог, а Option B слишком медленен. Обязательно требует этапа дедупликации и очистки.
