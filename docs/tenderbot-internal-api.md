# Внутренний API Tenderbot: выгрузка ID лотов

Публичный API `api.tenderbot.kz/api/external/v1` платный: 150 000 ₸ в год, токен выдаёт поддержка.
Сайт `tenderbot.kz` при этом ходит в собственный API `api.tenderbot.kz/api` по обычному логину аккаунта.
Через него можно бесплатно получить те же лоты, включая официальный номер объявления (`source_id`),
`GZID` и ссылку на карточку на goszakup.gov.kz.

Это неофициальный интерфейс: Tenderbot может поменять его без предупреждения. Годится для разового
среза и оценки пробелов, **но не для ежедневного сбора**. Для промышленной интеграции нужен купленный API.

## 1. Логин

```
POST https://api.tenderbot.kz/api/login
Content-Type: application/json

{"login":"sales1@promenergo.kz","password":"...","remember":true}
```

Ответ содержит `accessToken` — JWT на год. Дальше он передаётся заголовком:

```
Authorization: Bearer <accessToken>
```

401 — неверный логин/пароль, 403 на `/login` — временный бан за частые попытки.

## 2. Поиск лотов

```
POST https://api.tenderbot.kz/api/lots
Authorization: Bearer <accessToken>
Content-Type: application/json
```

Тело — те же фильтры, что собирает сайт:

| Поле | Смысл |
|---|---|
| `searchstr` | фразы через запятую, **OR** |
| `excluded` | массив слов-исключений |
| `tru_codes` | коды ТРУ/НСТРУ, OR |
| `subject` | `["1"]` товары, `["2"]` услуги, `["3"]` работы |
| `kato_id` | ID регионов из `/api/references/...` сайта |
| `summ` | `["от","до"]` по сумме |
| `open_date`, `close_date` | `["YYYY-MM-DD","YYYY-MM-DD"]` |
| `markPko`, `markInvalid` | `1`, чтобы пометить ПКО/недействительные |
| `exactNameOnly` | `"1"` — точное совпадение названия |
| `page` | страница, с 1 |
| `per_page` | размер страницы, **максимум 400** (больше — сайт молча отдаёт 26) |
| `export_xls` | `true` — вместо JSON вернуть xlsx со **всеми** строками выдачи |

Пустое тело `{}` — все активные лоты (≈48 800 на 25.11.2026).

Пример:

```bash
curl -sS https://api.tenderbot.kz/api/lots \
  -H "Authorization: Bearer $TB" \
  -H "Content-Type: application/json" \
  --data '{"searchstr":"ноутбук,монитор","per_page":400,"page":1}'
```

Ответ:

```json
{
  "success": true,
  "aData": {
    "lots": {
      "current_page": 1, "per_page": 400, "last_page": 1, "total": 157,
      "data": [{
        "id": 38614671,
        "source_id": "88811722-ЗЦП2",
        "name_ru": "Ноутбук",
        "amount": "175000.00",
        "customer": "ГУ \"Отдел образования ...\"",
        "bin_inn": "191240002002",
        "count": "1", "price_per_unit": "175000.00", "measure": "Штука",
        "delivery_place": "Акмолинская область, ...",
        "tenderOpenDate": "2026-11-25 14:15:00",
        "tenderCloseDate": "2026-11-27 14:15:00",
        "tender": {
          "gzid": "G18020190-1",
          "link": "https://goszakup.gov.kz/ru/announce/index/18020190"
        }
      }]
    }
  }
}
```

`aData.lots.total` — сколько всего совпадений, `last_page` — сколько страниц.

Без токена тот же запрос работает, но `tender.gzid` = `"hidden"` и `tender.link` = `null`.
С токеном отдаются реальные GZID и ссылки.

## 3. Как забрать все ID

Вариант А, JSON: `per_page: 400`, затем `page: 1..last_page` с паузой 1–2 с между запросами.

Вариант Б, Excel: тот же POST с `"export_xls": true` — один запрос, в ответе xlsx со всей выдачей
(`Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`), `per_page`
игнорируется. На 157 лотов файл весит ~49 КБ и содержит все 157 строк.

## 4. Лимиты и баны

- Счётчика запросов, как у платного API (3 000 в день), нет, но залп режется.
- При частых запросах приходит `403` с текстом `You got banned permanently from this server.`
  Бан снимается сам через несколько секунд. Держите паузу 1–2 с, на 403 — ретрай с backoff.
- `per_page` больше 400 не ошибка: сервер просто вернёт `per_page: 26`.
- Старый токен после нового логина не умирает, а начинает отдавать `200` со скрытыми полями:
  `source_id`, `customer`, `bin_inn`, `gzid` приходят как `"hidden"`, `link` — `null`. Название,
  сумма и даты при этом остаются, поэтому такую выдачу легко принять за нормальную. Клиент проверяет
  первый лот и сам перелогинивается, но при ручных запросах токен берите свежий.

## 5. Скрипт

`scripts/tenderbot-export-ids.mts` логинится по `TENDERBOT_LOGIN` / `TENDERBOT_PASSWORD` из `.env`,
ищет каждый товар отдельно, складывает ID, GZID и ссылки в CSV/JSON и пишет сводку по совпадениям.

```bash
# наши товары из конфига, по 5 страниц на слово
npx tsx scripts/tenderbot-export-ids.mts --config config/gz-lots-computers.json --max-pages 5

# свои фильтры
npx tsx scripts/tenderbot-export-ids.mts --keywords "ноутбук,монитор" --amount-from 500000 --region 7522887

# одно слово, точное совпадение, без исключений
npx tsx scripts/tenderbot-export-ids.mts --keywords "сервер" --tru 262011.100.000000
```

Результат по умолчанию — в `outputs/tenderbot-ids-<дата>/`: `ids.csv`, `lots.json`, `summary.json`.
Ничего не пишется в Bitrix, скрипт только читает.

## 6. Разбор выгрузки: где реальный пробел

Общий счёт обманывает: большинство лотов мы и так собираем. `scripts/tenderbot-platform-report.mts`
раскладывает выгрузку по площадкам и оставляет в пробеле только непокрытые площадки и наши товары.

```bash
npx tsx scripts/tenderbot-platform-report.mts --in outputs/tenderbot-ids-gz-computers/lots.json
```

На выгрузке от 25.11.2026 (порог 500 000 ₸):

| Площадки | Лотов | Из них наших | Вывод |
|---|---|---|---|
| goszakup.gov.kz | 164 | 117 | собираем, воронки ГЗ |
| Самрук-Казына, Mitwork, Tizilim | 43 | 13 | собираем, F3 |
| Omarket, ЭТБ, EurasianTech | 51 | **40** | **не собираем, реальный пробел** |
| med.ecc.kz, Нацбанк, «Алина» | 14 | 1 | не наш товар |

Итог: из 272 лотов реальный пробел — **40 лотов на 148,9 млн ₸**, больше половины на Omarket
(панели, ЖК-панели, компьютеры). Остальное — госзакупки и F3, которые уже в сборщиках.
Мониторы, «стол», «процессор», «учебное оборудование» в выгрузке — шум широких слов.
mp.kz не попал: у лотов нет суммы, порог 500 000 ₸ их отсёк.

## 7. Риски

- **Бан аккаунта.** Сервер отвечает `banned permanently` уже на серию запросов. Скрипт ретраит,
  но при массовой выгрузке аккаунт можно потерять. Пауза меньше 1 с не рекомендуется.
- **Тариф.** Аккаунт на «Старте» до 10.12.2026 и привязан к Google-почте другой компании, не F3.
  После окончания тарифа, скорее всего, пропадут номера закупок и ссылки — выгружать нужно сейчас.
- **Нестабильный контракт.** Внутренний API не версионируется, поля могут переименовать без анонса.
- **Условия Tenderbot.** API продаётся за 150 000 ₸ в год; массовая выгрузка через сайт может
  расходиться с их офертой. Для ежедневного сбора надёжнее оплатить доступ.

## 8. Что важно помнить

- `id` лота — внутренний идентификатор Tenderbot, для goszakup используйте `source_id`/`gzid`.
- Выдача ограничена активными лотами; архив — через `link: "lots.list.unactual"` (POST `/api/lots`
  с `link`) или отдельную страницу «Итоги».
- Цена за единицу и количество приходят строками — приводите к числу на своей стороне.
- Логин-пароль сайта = доступ ко всему аккаунту; в чат токен не пересылайте.
